## Dataset Catalog

_open-PPG_ provides a catalog of datasets containing photoplethysmography (PPG) signals. The catalog provides a list of many publicly available datasets, as well as some restricted access datasets that can be used in research. The list of datasets can be filtered to identify datasets that match your needs.

### Contributing

We appreciate contributions to help expand the list and keep it up to date.

* **Suggesting additional datasets:** If you would like to suggest an additional dataset then please complete [this form](https://docs.google.com/forms/d/e/1FAIpQLScgsnaZRB5r3kn4WBKyx6IomWOuclaxffszmRkwLyHdRNZR0w/viewform?usp=dialog).
* **Highlighting errors:** If you spot an error in the current list of datasets, then please open an issue [here](https://github.com/open-ppg/data/issues).
